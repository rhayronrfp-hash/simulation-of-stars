# simulation-of-stars
A star simulator developed in C++ and OpenGL, focused on the visual and computational representation of celestial bodies and their behavior.


<h2>Technologies</h2>

<ul>
  <li><a href="https://isocpp.org/">C++</a></li>
  <li><a href="https://www.opengl.org/">OpenGL 3.3</a></li>
  <li><a href="https://www.glfw.org/">GLFW</a></li>
  <li><a href="https://glad.dav1d.de/">GLAD</a></li>
  <li><a href="https://github.com/g-truc/glm">GLM</a></li>
  <li><a href="https://github.com/nothings/stb">stb_image</a></li>
  <li><a href="https://registry.khronos.org/OpenGL/">GLSL (Shaders)</a></li>
</ul>
